## What You Will Need

Every new arrival should be equipped with the essential tools and access required to navigate the organization. These are the basics.

### Communication

The organization communicates primarily through channels designed for asynchronous, written discussion. Default to public channels and threads. Decisions should be visible and discoverable by anyone who might need context later.

### Documentation

Documentation is a first-class practice here. Every significant decision, process, and piece of context should be written down and discoverable. If you learned something the hard way, document it so the next person does not have to.

### Code and Tooling

The development environment is containerized and reproducible. A single command should bring up a working local stack. If it does not, that is a bug — report it, then fix it.

### Support

You are not expected to figure everything out alone. Every domain has a primary point of contact. The organization values asking questions over pretending to know. Reach out early and often.
